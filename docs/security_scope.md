# Security scope (public)

SciNetX is distributed to licensed users via a gated channel.
This public repository is a documentation/landing repository and does not contain the implementation source code or distributed artifacts.

## Reporting
Security issues should not be reported in public issues.

- Security policy: [SECURITY.md](https://github.com/madavid128/SciNetX-Public/blob/main/SECURITY.md)
- Email: michael.david@cuanschutz.edu

## What to include
- affected artifact type (desktop/Docker/other)
- build identifier or portal release ID
- environment details and a redacted reproduction description
