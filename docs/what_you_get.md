# What you get with SciNetX

SciNetX gives teams a clear, repeatable package of analysis results plus a dedicated interface for reviewing them.

## What SciNetX delivers

### Summaries and trends
SciNetX organizes results into views that help users review publication activity, trends over time, and high-level patterns across a dataset.

### Exportable tables
Users can work from structured tables for reporting, downstream analysis, and internal review.

### Figures and visual outputs
SciNetX produces ready-to-review figures and visual summaries that support presentations, manuscripts, and internal decision-making.

### Network views
When network analysis is part of the run, SciNetX provides relationship views that help users inspect connections among authors, venues, topics, or other entities.

### Run summaries
Each licensed delivery is designed around a repeatable results package so users can revisit prior analyses and understand what was produced.

## How people use it

### Before access
Start with the overview at [scinetx.com](https://scinetx.com), read about the workflow, and request access if SciNetX looks like a fit.

### After access
Onboarding and release access are available through [portal.scinetx.com](https://portal.scinetx.com), along with the delivery format appropriate for the environment.

- Desktop application
- Docker-based deployment
