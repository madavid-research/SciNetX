# CI & releases

This public record repository does not build or publish SciNetX artifacts.

Licensed users receive builds through [portal.scinetx.com](https://portal.scinetx.com). Release artifacts may include desktop bundles, a Docker image reference, compliance notices, and a source snapshot zip on request under the applicable license.
