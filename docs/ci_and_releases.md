# CI & releases (public)

This public repository does not build or publish SciNetX artifacts.

Licensed users receive builds through an institution portal. Release artifacts may include desktop bundles, a Docker image reference, compliance notices, and a source snapshot zip on request under the applicable license.

For details, see:
- [releases.md](releases.md)
- [licensing.md](licensing.md)
