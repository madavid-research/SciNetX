# Releases (institution portal)

SciNetX releases are distributed to licensed users via an institution portal.

Typical release contents:
- Desktop bundles (macOS/Windows; optional Linux)
- Docker image (via institution registry) and a pinned digest
- Compliance bundle (third-party licenses/notices + inventories)
- Source snapshot zip (provided on request or separately gated)
