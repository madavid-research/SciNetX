# FAQ

## Is the source code public?
No. SciNetX is source-available under gated distribution. Licensed users receive release artifacts via an institution portal; source snapshots are provided on request under the applicable license.

## How do I get access?
See [REQUEST_ACCESS.md](https://github.com/madavid128/SciNetX-Public/blob/main/REQUEST_ACCESS.md).

## What do I need to run it?
Licensed users receive platform-specific bundles (desktop/Docker) and documentation from the institution portal.

## Can I cite SciNetX?
Yes. See [CITATION.cff](https://github.com/madavid128/SciNetX-Public/blob/main/CITATION.cff).

## Where are the third-party notices?
Licensed distributions include a third-party notices bundle and license inventories.
