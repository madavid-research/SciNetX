# Known issues

This page lists commonly reported issues in distributed artifacts to reduce duplicate reports.

## Before filing a bug
- Confirm the build identifier: see [versioning.md](versioning.md).
- Review redaction guidance before sharing logs/screenshots: see [redaction_guide.md](redaction_guide.md).

## Common reports
No known issues are listed publicly yet.

If you encounter a bug, please file a report and include the build identifier and environment details:
- Bug report form: https://github.com/madavid128/SciNetX-Public/issues/new?template=bug_report.yml

If an issue is repeatedly reported, a short entry can be added here with:
- affected artifact types (desktop/Docker/Colab)
- affected versions/build identifiers
- workaround (if any)
- status (investigating/fixed in X.Y.Z)
