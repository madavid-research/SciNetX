# SciNetX (Public Overview)

This repository is a public landing page for SciNetX.

SciNetX is distributed to licensed users via a gated institution portal. It produces an `output/` workspace and provides a UI to explore results.

For access requests, see [REQUEST_ACCESS.md](https://github.com/madavid128/SciNetX-Public/blob/main/REQUEST_ACCESS.md). Portal details/URLs are shared with licensed users during onboarding.
