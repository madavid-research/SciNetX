# Labels

This page documents the recommended label set for issue triage. Labels are created and managed in the GitHub repository UI.

## Recommended labels
- `access-request`: (deprecated) misfiled public access/licensing requests (should be redirected to private channels)
- `bug`: bug reports against distributed artifacts
- `question`: general inquiries
- `docs`: documentation-only changes/issues
- `security`: security-related reports (public issues should be avoided; this can be used as an internal marker if needed)

## Suggested usage
- Avoid handling access requests via public issues; close/redirect them to [../REQUEST_ACCESS.md](../REQUEST_ACCESS.md).
- Apply `bug` to reports that include a build identifier and reproduction steps.
- Apply `question` for public-safe questions; route sensitive items to email.
- Apply `docs` for improvements to `README.md` and `docs/`.
