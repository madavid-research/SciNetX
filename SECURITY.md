# Security policy (public)

SciNetX is distributed to licensed users via a gated channel. Do not post vulnerabilities publicly.

## Scope
This repository is a public documentation/landing repository and does not contain the SciNetX implementation source code.

Security reports should reference the affected distributed artifact (desktop/Docker/other) and its build identifier.

## Reporting
Email: michael.david@cuanschutz.edu

Include:
- Affected version/build identifier.
- Environment details.
- Steps to reproduce and impact assessment.
