# SciNetX v1.0.0 Zenodo Record

This package is the citable Zenodo record for **SciNetX v1.0.0**.

SciNetX is a Python-based platform for bibliometric, scientometric, and network analysis of scientific literature. It supports reproducible workflows for literature ingestion, cleaning, analysis, and visualization across citation, co-authorship, keyword, institutional, and related research networks, and may integrate sources such as PubMed and OpenAlex.

SciNetX can also operate on custom datasets with or without associated literature papers, including broader general network analysis workflows outside literature-centered use cases.

SciNetX is distributed through a controlled academic/commercial access model. This Zenodo package is a **public citation record only**. It contains metadata, provenance, access information, and branding assets, not the software itself.

## Scope and exclusions

This record includes high-level software description, citation metadata, version details, provenance, and access guidance.

It does not include source code, executables, model weights, proprietary workflows, internal configuration, private schemas, deployment details, or other controlled delivery artifacts. Feature availability may vary by approved access pathway and license terms.
